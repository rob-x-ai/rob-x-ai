# Robin Kroonen

**Founder & CEO, [Kroonen AI](https://kroonen.ai)** · Delaware, USA

Building the **Libre ecosystem** — privacy-first AI infrastructure, terminal agents, communications systems, and model research for teams that refuse bloated SaaS stacks.

---

### The Libre Stack

| Project | What it is | Links |
|---|---|---|
| 🕊️ **Libre WebUI** | Self-hosted AI chat interface for Ollama & 10+ cloud providers. Plugin system, RAG, artifacts, SSO, desktop app. Apache 2.0 forever. | [Website](https://librewebui.org) · [GitHub](https://github.com/libre-webui/libre-webui) |
| 🦞 **Libre Claw** | Terminal-native AI coding agent harness. Textual TUI, durable runs, persistent memory, Telegram bridge, multi-provider routing, browser tools. | [Website](https://libreclaw.sh) · [GitHub](https://github.com/kroonen-ai/libre-claw) |
| 📞 **Libre Phone** | Twilio-powered cloud phone system on Cloudflare Workers. Calls, SMS/MMS, voicemail, IVR, WebRTC — for ~$1/month. | [Website](https://kroonen.ai) |
| 🤖 **Libre Bot** | AI documentation assistant widget. Add intelligent chat to any docs site in 5 minutes. | [Website](https://librebot.ai) |
| 🧬 **Genesis 1B** | 1B parameter language model pretrained from scratch on 2× RTX 4090. Custom tokenizer, 60B token multilingual dataset, 80K steps complete. | [Playground](https://huggingface.co/spaces/rob-x-ai/genesis-1b-run2-playground) |
